# UI/UX Quality Gate - 2026-10-23

## Scope

This review covers the local Windows WinForms client after the Steam library discovery and usability pass. It does **not** certify that every Steam title supports claims or that every screen reader / physical DPI arrangement behaves identically.

## Completed improvements

- Installed-game catalog from local `appmanifest_*.acf` and libraryfolders, including extra Steam libraries.
- Searchable, bilingual **My games** picker with installation paths and AppIDs, explicit manual Browse fallback and a themed scrollbar for overflow.
- Asynchronous library enumeration and game detection to keep the main window responsive.
- Clear first-run instructions, predictable Rescan enablement, keyboard shortcuts `Ctrl+L`, `Ctrl+F`, `F5`.
- Compact diagnostics panel that preserves at least one complete achievement row at the minimum window size.
- Existing explicit achievement checks, confirmation, hidden-selection count, filters and read-only scanning retained.
- Windows build script tolerates a locked repository-root EXE; newest build and UI regression target remain under `dist/`.

## Verification

- Native UI regression: **83 PASS, 0 FAIL** on the Windows development machine.
- Manifest fixtures: valid/invalid AppIDs, Unicode names, duplicate libraries, folder traversal rejection and missing install folders.
- Picker fixtures: 2-game search, empty results, 24-game overflow, selection, themed-scrollbar navigation.
- UI fixtures: English/Vietnamese, minimum window, activity log, custom themes, 150% simulated scaling, empty state, confirmation safety.
- Real installed-game discovery (read-only): **16 installed games detected**.
- No real Steam achievement claim was triggered by these tests.

## Known validation limits

1. Live Steam API listing and claiming, game-specific failure handling and reversibility have **not** been re-certified.
2. Physical 125%/150%/200% DPI monitors and assistive-technology workflows have not been independently tested.
3. WinForms `DrawToBitmap` renders client surfaces and does not prove the color of the OS-composited native titlebar.
4. If Windows locks `UmiAchievementClaimer.exe` at the repository root, the executable there may be older than the source. Run `dist/UmiAchievementClaimer.exe` to test the newest build.

## Remaining acceptance gates for a defensible 10/10

Perform hands-on task success tests with first-time and returning users; test keyboard-only and screen reader workflows; check several actual display DPI configurations; verify representative Steam games in read-only mode and carefully review the claim workflow with an authorized test account; collect crash logs and usability observations. Passing scripted UI tests alone is insufficient evidence for a perfect score.
