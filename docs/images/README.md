# UI screenshots

The six `ui-*.png` screenshots correspond to the **v1.11.3 WinForms UI** and originate from synthetic native UI regression runs. They contain no real Steam account information or real achievement claims.

- `ui-home.png` - first-run state and upper-right assembly version.
- `ui-log.png` - Activity log on its **first** expansion; idle ProgressBar hidden.
- `ui-settings.png` - bilingual language and theme preferences.
- `ui-insights.png` - snapshot/achievement metrics and recovery tools.
- `ui-empty-game.png` - safe game-with-zero-achievements state.
- `ui-library.png` - searchable installed-game picker (synthetic installed game manifests).

The screenshots are client renders and do **not** include native Windows compositor-controlled frame details. Historical screenshots were removed from the current tree and are accessible through previous Git revisions. All screenshots are documentation; images are not embedded into the compiled desktop application.

- `ui-log-small.png` - compact expanded log with fully visible first-run guidance after changing layout padding.
