# Umi Achievement Claimer 1.10.0 — Quality gate (2026-10-23)

## Shipped in local source

- Steam preflight checks local Steam process, game directory, AppID, source API path, architecture and compatibility-provider caveats.
- Four achievement sort modes (original, name A–Z, locked-first, unlocked-first), preserving explicit checked selections.
- Read-only achievement inspector on row double-click.
- Steam installed-game picker Favorites, Favorites-only toggle and recently-used ranking, persisted as **Steam AppIDs only** under AppData.
- Worker Cancel and automatic timeout (90 seconds for list, 120 seconds for selected claim); interrupted claims are explicitly reported as **uncertain**, never automatically retried.
- Worker Steam API readback is now summarized as **verified locally X/Y** and **accepted X/Y**, with an explicit warning that it does not prove remote Steam-server synchronization.
- Windows portable packaging script, SHA-256 checksum output and tag-triggered GitHub Actions release workflow.

## Evidence

- Current synthetic native regression suite: **98 PASS / 0 FAIL** (Windows).
- Confirmed cancellation/timeout using non-Steam test processes; no game profile was modified.
- Steam library/search/favorite tests operate on synthetic appmanifests and an isolated temporary preference file.
- Manual review of render captures: main window, minimum window, 150% simulated scaling, Steam library, inspector, Settings and confirmation.
- Current build produced at `dist\UmiAchievementClaimer.exe`; packaging generated `dist\UmiAchievementClaimer-v1.10.0-windows-x64-portable.zip`.
- GitHub Actions exists but runs only after changes are pushed and the runner starts; a locally passing suite **is not** evidence CI succeeded.
- Real Steam claims were **not executed**.

## Still unverified / intentionally not shipped

- True server-side persistence cannot be independently confirmed by the local Steam API readback.
- Game-specific compatibility, anti-cheat/protected games and real Steam claim behavior remain unverified.
- Accessibility with assistive readers, physical DPI at 125/150/200%, and real-user usability sessions remain pending.
- No in-game overlay, web-based Steam cloud account access or telemetry was added; these increase complexity and risk.
- Automatic release requires an explicit version tag, and public publishing should wait until a real-world smoke test is approved.

## Notes

The repository-root EXE may remain locked by another process. The build deliberately does not kill that process; use the freshly built executable under `dist`. The build/test scripts and release package always take the `dist` executable.
