# Umi Achievement Claimer 1.11.0 — Insights and Recovery QA

## Delivered
- **Global achievement rarity** via Steam's unauthenticated public statistics endpoint. Real percentages fetched asynchronously after a successful read-only achievement scan. If API data is unavailable, rarity stays N/A rather than guessed. Ultra Rare (≤5%) and Rare (≤20%) are Umi UI classifications, not Steam's official tiers.
- **Unlock timeline** from optional Steam UserStats flat export `GetAchievementAndUnlockTime`. Games without the export return unknown timestamps and continue functioning. The legacy 5-field worker protocol remains supported; the new optional sixth field carries Unix seconds.
- **Local snapshots** saved in `%APPDATA%\UmiAchievementClaimer\history` only on successful list reads. Per-game snapshots are retained up to the last 30 unique states. No account tokens, file paths or credentials are stored.
- **Insights Dashboard** reports local games, unlocked totals, snapshot history and timeline changes. Double-click a game to see dated local snapshot events; export current game's latest snapshot as CSV with spreadsheet-formula safety.
- **Recovery Center** persists an explicitly selected pre-claim baseline and compares it to the next read-only state. Reports newly unlocked, unchanged and missing IDs. No automatic claim retries. Users can dismiss recovery notes manually without changing Steam.
- **Smart Update Check** only compares the installed assembly version to the public GitHub Releases latest tag. It may open the official Releases page on user approval but does not download, install or execute code.
- **Existing safety**: explicit selection/confirmation, worker timeouts and manual cancellation continue working.

## Verification
- Windows application builds for x64 with embedded x86/x64 workers. Existing WinForms regression plus added snapshot, rarity, historical protocol, CSV and recovery tests: **112 PASS, 0 FAIL** on local Windows.
- Snapshot fixtures use isolated temp storage, not the user's AppData; no claim was executed.
- Inspected main UI, achievement inspector and Insights dashboard rendered at native test resolutions.
- Public rarity endpoint was queried for game ID 620 and returned HTTP 200 with JSON aggregate percentages. Other games may have unavailable statistics.
- Tests do not validate actual Steam runtime unlock timestamps for each game, actual claim persistence or physical DPI across devices.

## Trust boundaries / known limitations
- The snapshot store is scoped to the Windows user profile and app ID, **not Steam account ID**. If several Steam accounts use the same Windows profile and game, comparisons could mix those accounts. Avoid interpreting history as per-account proof.
- API readbacks and snapshot comparisons do not independently verify server synchronization.
- Local snapshot files are not encrypted. Do not use them on an untrusted shared Windows account.
- Steam global percentages are public aggregates, not current-user achievement status.
- Historical unlock time reports "Not available" if export returns no valid time, including older unlocks.
- A standalone auto-updater, unverified binary downloads, in-game overlay and automatic Claim retries are intentionally excluded.
